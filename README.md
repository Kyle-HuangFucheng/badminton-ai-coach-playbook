# 羽毛球 AI 训练 App · 开发实战手册(Playbook)

> 一款羽毛球 AI 训练 iOS App(SwiftUI + watchOS + FastAPI)从基础版走到完整版的**开发路线图与避坑手册**,整理自真实项目实战。
> 全部关键决策、任务拆解和踩过的坑,供开发者与 AI 编程工具在开发同类产品时参考,少走弯路。

## 产品形态

面向业余羽毛球爱好者的 AI 训练助手:

- **拍一段挥拍视频 → 全自动分析**:姿态骨架、逐拍切分、肘角/击球点标注、AI 教练点评 + 中羽 1-7 级评级,全流程无需手动操作;
- **个性化课程**:按用户画像(水平/身体/条件/目标)秒配 3 阶段 12 课,可让 AI 微调;
- **Apple Watch 双端**:手表独立快练(拍数/挥速/心率),回手机自动生成档案;腕上遥控手机开拍;
- **球友圈社区**:约球/求指点/晒战报/球馆点评,评论、配图、私聊、Apple 登录;
- **内容库三件套**:110 种常见错误(对错示范插画)、100 套训练方法、30 讲知识讲堂 + 战术板。

隐私原则:视频与姿态数据全部只存在手机本地,AI 只收匿名的数据摘要与关键帧。

## 技术栈

| 层 | 选型 |
|----|------|
| iOS App | SwiftUI,iOS 17+,手写/xcodegen 维护 xcodeproj |
| 手表 | watchOS 10+,WatchConnectivity 双通道协议 |
| 视频分析 | Vision(姿态)+ 自研挥拍检测(全在设备本地) |
| AI | 豆包 doubao-seed-2.0-lite,经自建服务器代理(客户端零配置) |
| 后端 | FastAPI + SQLite,单机单进程部署 |
| 动效 | Pow + Vortex(SPM) |

## 这个仓库怎么用(给 AI IDE 的使用说明)

1. **开工前**:先通读 [ARCHITECTURE.md](ARCHITECTURE.md) 建立整体认知;
2. **按里程碑推进**:[ROADMAP.md](ROADMAP.md) 把"基础版 → 完整版"拆成 M1-M6 六个里程碑,
   每个里程碑给了任务方向和验收标准,按顺序做;
3. **动手前查坑**:每个里程碑标注了"高危坑",对照 [PITFALLS.md](PITFALLS.md) 相应条目先读再写;
4. **后端**:[BACKEND.md](BACKEND.md) 有本地一键跑法和接口清单,开发期一律连本地,不碰线上;
5. **素材**:插画/示例视频/内容库文案等现成资产见 [ASSETS.md](ASSETS.md) 清单,到对应里程碑再要。

## 一条经验总纲

这个项目最重要的三条纪律,贯穿所有里程碑:

1. **每改一批就双端 build 一次**,别攒;新增 Swift 文件必须确认进了工程文件(见 PITFALLS #1);
2. **凡是跨设备/跨线程的状态,先想清楚"晚到、重复、乱序"三种情况**再落盘(见 PITFALLS 手表章);
3. **用户看得见反馈**:任何操作要么有结果、要么有错误提示,静默失败等于 bug(见 PITFALLS 体验章)。
